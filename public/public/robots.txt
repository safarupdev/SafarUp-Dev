# KNOWN LIMITATION — client-side rendering (CSR). NOT resolved.
#
# This is a Vite single-page application. Every route is rendered by
# JavaScript in the browser, so a crawler that does not execute JavaScript
# receives only the app shell: one <title>, no per-route description, and no
# per-route <link rel="canonical"> or JSON-LD. Per-route document head is
# written at runtime (public/src/lib/seo.js), which Google and most crawlers
# do render, but this is not a guarantee for any crawler.
#
# The planned fix is pre-rendering (or SSR) of the indexable routes so each
# URL is served as real HTML. This is a LAUNCH BLOCKER and is tracked as such;
# it is not addressed by robots.txt or by the sitemap. See
# docs/PUBLIC_CRAWLER_FOUNDATION.md.
# ---------------------------------------------------------------------------

# Reserved routes. These render an explicit "not available yet" state and emit
# `noindex,follow`, but disallowing them keeps crawlers from spending crawl
# budget on pages that must never appear in an index.
#   /blog                — blog is not built (Phase 3)
#   /login               — authentication is Phase 4
#   /dashboard/bookings/*— member dashboard is Phase 4
#   /places/:slug        — RESERVED, noindex: whether a Place has a public page
#                          is undecided (PRD §200.6/§200.9)
Disallow: /blog
Disallow: /login
Disallow: /dashboard/
Disallow: /places/
